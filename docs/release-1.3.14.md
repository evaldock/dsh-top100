# 1.3.14：DSH Desktop 兼容与导航调整

Top100 1.3.14 增加 DSH Desktop 0.2.0-rc.2 支持，保留原有 Web 版使用方式。桌面版实机验证范围为 macOS ARM64。

## 变化

- 安装、更新、启停和卸载绑定桌面宿主的实际 Profile，使用官方内置包管理器与 Profile 写锁，不要求另装全局 Node、pnpm 或 dsh。
- 兼容桌面应用的请求转发和登录鉴权；修复宿主版本识别与诊断依赖定位。需要重启时提示退出并重新打开桌面应用。
- 作者的标准 Web 安装示例可在桌面提取安装源，实际操作仍作用于 `desktop` Profile；自定义 Profile 和私有 registry 限制保留。
- 页面导航采用浅紫色圆角选中背景和紫色文字，移除选中下划线，字号调整为 13px。

## 更新方式

桌面版先打开一次应用初始化环境，在菜单“管理 dsh 命令”中安装官方命令，完全退出桌面应用后执行：

```sh
dsh plugin --profile desktop add @evaldock/dsh-top100-plugin@1.3.14
```

安装完成后重新打开应用。桌面和 Web 使用独立 Profile，安装到 Web 不会自动安装到桌面。详见[桌面兼容说明](./desktop-compatibility.md)。

Web 用户沿用原来的命令前缀、Profile 和 DSH_HOME，安装后重启：

```sh
dsh plugin --profile web add @evaldock/dsh-top100-plugin@1.3.14
```

仍使用旧包名的用户请先按[包名迁移说明](./release-1.3.11.md)操作，避免加载两份 Top100。

## 验证与边界

最终 1.3.14 安装包通过类型检查、945 项插件测试、108 项网站测试、8 项安装包检查、版本一致性检查与依赖审计（0 漏洞）。90 个包内文件与隔离桌面、旧 Web 实际安装目录逐一匹配。官方 macOS ARM64 Desktop 0.2.0-rc.2 中已检查市场搜索、分类、排序、Skill 安装预检与取消、已安装列表刷新和诊断。使用官方安装包内的 Electron 44.0.0 / Node 24.18.1、ASAR 模块及自带 pnpm，在隔离 Profile 完成实际安装、升级、卸载和配置校验；另验证了桌面 HTTP 启停、卸载与官方协议转发鉴权。

旧 DSH Web 0.1.5-rc.3 的加载、同端口重启和诊断回归通过。测试操作未改动日常 Profile，未继承模型密钥或发起模型请求。

诊断为零错误、零提醒；Top100 自身已确认运行，宿主内置 `dsh-base` 的加载状态仍标为待确认。Skill 实际复制与回滚以自动化测试为证据。未逐个验证市场第三方插件，未做 Windows/Linux 实机验证；安装按钮与依赖范围匹配不等于第三方功能或安全审核通过。
