# 1.3.10 EvalDock 配色与新版 DSH 适配

插件采用与 Top100 官网一致的浅色紫色界面，官网链接和默认数据源改为 EvalDock。npm 包名仍为 `@dsheval/dsh-top100-plugin`，已有自定义数据源不会被覆盖。

- 插件和 Skills 市场在快照超过 36 小时未更新时提示数据日期；缓存读取失败提示继续保留。只有日期时按北京时间整日计算，重新发布旧数据不会刷新其时效。
- 适配 DSH Web `0.1.6-alpha.2` 的插件管理页，可在侧栏 **插件 → top100-plugin** 保存榜单数据源。
- 保留 DSH Web `0.1.5-rc.2`，设置入口为 **设置 → 插件 → 插件配置 → 榜单数据源**。榜单仍在 **设置 → 插件排行**。
- 修复插件停用后语言包未注销的问题，支持新版宿主重新启用时恢复界面。

继续推荐 DSH Web `0.1.5-rc.2`；已使用 `0.1.6-alpha.2` 的用户可安装本版，无需为了插件主动切换至 alpha。既有安装审核、来源检查和模型调用限制不变。

验证：类型检查、1808 项测试通过，1 项原有测试跳过；隔离的真实 DSH Web `0.1.5-rc.2` 与 `0.1.6-alpha.2` 均使用实际候选 npm 包启动，接口返回 1.3.10 与当天榜单。浏览器检查了新旧设置入口、数据源保存、榜单、搜索、Skills 和诊断，新版宿主禁用后重新启用无需刷新。未验证 Windows 或第三方 Desktop 宿主。
