# 1.3.13：DSH 0.2 兼容更新（待发布）

增加 DSH 0.2.0-rc.1 的依赖兼容声明，继续保留旧版 DSH 支持。无需为了升级 Top100 更换 DSH 版本。

## 变化

- 接受 DSH 0.2.0-rc.1 的 settings、skill 和 tools 包版本，并增加 0.1.7-rc.2 / 0.2.0-rc.1 版本匹配测试。
- 安装状态统一为“未找到安装命令”“安装信息暂未核实”“安装信息需重新核对”等清楚的说明，并同步英文。
- “已找到安装命令”仅表示有安装目标；“安装信息已核对”仅表示核对安装包资料，不代表实际安装、功能或安全验证通过。
- 区分“插件身份待确认”与“功能说明待确认”；DSH Bundle 在界面中显示为“DSH 插件包”。保留现有布局与安装、配置、更新流程。
- 安装预检支持非空的多文件 `dsh.bundle.patch`，继续拒绝空项与非法类型。
- 安装与更新确认显示当前 DSH 版本、目标包的 DSH peer 范围及匹配/不匹配/未知状态，遵守官方预发布版本和范围上界语义；未声明要求不会标成兼容。版本豁免及最终加载仍由 DSH 处理，无法识别运行版本时显示未知。
- 更新确认提供精确 npm 版本页、GitHub 发布记录及锁定 commit 链接；标题旁以浅灰小字显示当前 Top100 版本，升级说明收进已安装 Top100 的详情，保持自身操作保护。
- 重新构建安装产物，同步源码中已有的仓库更名身份核对、保留已知安装检查失败状态及旧简介提示修复。

## 更新方式

沿用原来的 DSH 启动方式、Profile 和 DSH_HOME，安装本版本后重启：

```sh
dsh plugin --profile web add @evaldock/dsh-top100-plugin@1.3.13
```

若使用 npx 启动，保留原来的 npx 前缀。仍使用旧包名的用户，先按 [包名迁移说明](release-1.3.11.md) 操作，避免同时加载两份 Top100。

## 验证与边界

本版本待发布。最终代码的类型检查、922 项插件测试、108 项网页测试、8 项安装包校验及版本一致性检查通过；官方 npm DSH 0.2.0-rc.1 类型声明检查通过。

兼容验收覆盖 DSH Web 0.2.0-rc.1 的安装、从 1.3.12 升级、配置及本地 Skill 保留、同端口重启恢复和诊断。旧版 npm DSH Web 0.1.5-rc.3 的安装、加载与重启也已通过。安装依赖检查保持开启，无需添加版本豁免。

浏览器核对了安装前版本提示、配置保存、页头版本号、已安装详情中的升级说明及字号。版本匹配只是声明核对，不代表所有功能已通过运行验证；无法识别运行版本时显示“未知”。

实机范围为 macOS / Node 26.8.1 / Web，未覆盖 Windows、Linux 或 Desktop 实机。0.1.7-rc.2 通过依赖范围检查，未单独启动实机。验证使用隔离 HOME / DSH_HOME，没有继承模型密钥、发起模型请求或修改日常 DSH 配置。
