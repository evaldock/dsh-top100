# 1.3.12：新版 DSH 兼容、重启与插件管理

适配 DSH 0.1.7-rc.1 的配置接口，并保留旧版接口兼容。在支持的本机 Web 环境增加一键重启；已安装页采用紧凑列表，诊断按结论、问题和高级详情分层。

## 更新

沿用现有 DSH 启动方式、版本、Profile 和 DSH_HOME，执行：

```sh
dsh plugin --profile web add @evaldock/dsh-top100-plugin@1.3.12
```

如果平时通过 npx 启动，请将命令中的 `dsh` 换成原来的 npx 前缀。升级后重启。无需为了更新 Top100 更换 DSH 版本。仍使用 `@dsheval/dsh-top100-plugin` 的用户请先按照 [旧包迁移说明](release-1.3.11.md) 完成包名迁移，避免同时加载两份插件。

## 主要变化

- 支持新版配置表单和实时字段，保存失败有明确反馈；设置入口使用 Top100 排行图标。
- 本机 Web 一键重启提供页面内确认，恢复后显示结果；正在安装或写入时阻止重启。远程、桌面及识别到的服务管理环境提供对应操作说明。
- 已安装页采用紧凑列表；正常的“已加载”收进详情，列表突出待重启、加载失败、缺少服务和未验证等状态。开关只表示是否启用。
- 诊断按对象合并问题并给出处理建议，普通信息和技术依据默认折叠，导出仅包含受限摘要字段。
- 修复多文件补丁声明误报，以及同 npm 包名的分叉导致的榜单关联问题。诊断和已安装页使用相同的待重启判断。
- 保留 schemastery 3.18.2 兼容，避免旧版环境出现不必要的依赖版本提醒。

## 验证与边界

候选产物已通过隔离环境的干净安装、从已发布 1.3.11 替换升级、配置和用户技能文件保留、停用状态保留及一键重启检查。DSH Web 0.1.5-rc.3 与官方源码构建的 0.1.7-rc.1 均验证加载和重启后恢复；使用实际 tarball 安装，包内文件与安装后文件逐一核对。

正式版本号 1.3.12 的安装包已补验干净安装、从 1.3.11 升级与重启；两种环境均返回 0 错误、0 提醒。全项目类型检查、1836 项测试通过，1 项原有测试跳过；其中包括 878 项插件测试，另有 8 项安装包校验测试通过。浏览器验证了列表、诊断、详情与重启确认交互。实机验收基于 macOS / Node 26.8.1；未覆盖 Windows、Linux 桌面或第三方 Desktop 的实际重启。官方复合组件可能显示“未验证”，不应将其解释为故障或全部功能正常。

升级不更改数据源、用户补丁或既有启停选择。包名及配置命名空间保持不变。若需要回退，可用原 CLI 安装 `@evaldock/dsh-top100-plugin@1.3.11`，并按原方式重新启动。
